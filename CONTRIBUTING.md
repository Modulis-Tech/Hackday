# Contribuer

Merci de contribuer à Hacktoberfest Hack Day.

1. Créez une branche descriptive depuis `main`.
2. Installez les dépendances avec `npm install`.
3. Vérifiez vos changements avec `npm run lint`, `npm run typecheck` et `npm run build`.
4. Ouvrez une pull request concise, avec tests et description du changement.

N’ajoutez jamais de secret, de fichier `.env.local` ou de données personnelles à Git.
